# Carlos Silva · Personal Trainer

App de entrenamiento: landing, portal del cliente y panel del coach. Sitio estático (GitHub Pages).

- Configuración: `config.js` (datos del coach y conexión a Supabase).
- Sin `supabase.url` en `config.js` corre en modo demo (datos de ejemplo solo en el navegador). Para producción, completar `url` y `anonKey` (solo la clave **anon**, nunca la `service_role`).
